secops-agent — autonomous security-operations triage

Two-phase control flow. Phase 1 must produce a validated Plan before any tool runs. Phase 2 is a bounded act/observe loop: one LLM call per step, one tool call per step, every failure compacted and fed back. The core owns the loop; the model only ever proposes.

Robustness

  • • Plan rejected → reason fed back, retry once
  • • Tool error → one-line observation, not a traceback
  • • Same call fails twice → strategy-change event
  • • Step and failure budgets both hard-stop cleanly
  • • Every branch covered by an offline test

Where judgement lives

  • • Tools report facts: CVSS, owner, days open
  • • Policy documents carry the rules
  • • The LLM applies them and cites the document
  • • Code validates and constrains — never decides
  • • No hardcoded severity table anywhere

Safety

  • • Exactly one irreversible tool: escalate
  • • It refuses without approver + approval_ref
  • • Approval is a real tool call, recorded in the trace
  • • Synthetic data, disclosed in every report
  • • Run locally against Ollama and nothing leaves the host
